# Pre-launch checklist

- [ ] Approved production hostname and hosting target recorded
- [ ] Full database and uploads backup created and restore-tested
- [ ] URL replacement dry-run reviewed
- [ ] Explicit migration confirmation and launch approval recorded
- [ ] Hello Elementor, ThatBioTutor child theme, and ACF Free versions approved
- [ ] `wp tbt setup-site` completed without unresolved slug collisions
- [ ] Home, Classes, Sec 3, Sec 4, Results & Testimonials, Free Bio Notes, About, Contact, Our Causes, Tuition Recommendations, IntensiveFix, and 404 verified
- [ ] IntensiveFix confirmed separate from regular Sec 3
- [ ] Fixed numbered media order and WebP delivery verified
- [ ] Testimonials, Tutors, FAQs, and Results order/Draft behavior verified
- [ ] Legacy redirects, metadata, WhatsApp, YouTube, and external links verified
- [ ] 1440, 768, 390, and 320 pixel layouts checked
- [ ] DNS and SSL plan approved
- [ ] Mail delivery requirement resolved
- [ ] Analytics and consent decision resolved
- [ ] Cache purge and rollback owner assigned
- [ ] Post-launch verification and monitoring window assigned

Any unchecked production, DNS, mail, analytics, consent, backup, rollback, or launch approval item remains pending and blocks launch.
