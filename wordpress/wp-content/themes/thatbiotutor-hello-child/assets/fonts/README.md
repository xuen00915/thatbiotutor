# Font licensing

The public Wix capture contains font evidence, but captured font files are not automatically licensed for redistribution in this WordPress theme.

- The original Futura-style navigation is represented by the protected CSS font stack until the client supplies or confirms a redistribution licence.
- The preferred open replacement is Montserrat, which WordPress may load locally only from an approved open-licensed package.
- The initial source package intentionally contains no font binaries. System fallbacks keep the site readable if Montserrat is unavailable.

Do not copy font files from the crawl into this directory without recording the licence and source.
