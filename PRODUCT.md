# Product

ThatBioTutor is a Singapore O-Level Pure/G3 Biology tuition website. This package reproduces the original public pages in WordPress and adds IntensiveFix as a separate programme page without replacing regular Sec 3 tuition.

## Content ownership

- Clients edit approved page copy and fixed media through labelled ACF Free fields.
- Clients manage testimonials, tutors, FAQs, and structured results in dedicated WordPress admin areas.
- Developers maintain templates, navigation, section order, responsive behavior, metadata, redirects, and security.
- Shared header, footer, contact details, and floating WhatsApp render once across the site.

The package must remain portable to a future WordPress host and must not assume a final hostname.

IntensiveFix is separate from regular Sec 3 tuition. Production launch, DNS, mail, analytics, and consent remain externally approved operations, not repository defaults.
